# Task J3: Асинхронный обход ресурсов HTTP-сервера

Программа-«паук» обходит ресурсы HTTP-сервера, начиная с пути `/` и переходя по путям из поля `successors` каждого ответа. Обход выполняется параллельно на виртуальных потоках Java 21. Результат: все полученные сообщения, отсортированные в лексикографическом порядке.

## Запуск

1. Запустить сервер:
   ```bash
   java -jar Task_J3-server.jar <student_id> [порт]
   java -jar Task_J3-server.jar IvanIvanov 8080
   ```
   `student_id` это имя и фамилия латиницей слитно. Порт по умолчанию 8080.

2. Запустить паука:
   ```bash
   ./gradlew :java:task-j3:run --args="[порт]"
   ./gradlew :java:task-j3:run --args="8080"
   ```
   Сообщения выводятся в stdout по одному на строку. Если часть страниц получить не удалось, их список печатается в stderr, а программа завершается с кодом 1.
